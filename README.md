# Networkwalks-B084-Week-03-Assignment

NETWORKWALKS
WEEK 3 - PROJECT MODULE 1
PASSWORD CRACKING WITH JOHN THE RIPPER (JTR)


Project Module: 1

1. OBJECTIVE

The objective of this practical was to understand password security testing using John the Ripper (JTR) and its graphical interface, Johnny. The exercise involved setting up the required tools and working with the password-protected sample PDF provided in the NetworkWalks lab instructions.

2. INTRODUCTION

John the Ripper is a password security auditing tool used to evaluate password strength. Johnny is a graphical user interface that makes it easier to interact with John the Ripper.

This practical provided an introduction to both tools and their use in an authorized cybersecurity lab environment.

3. SOFTWARE AND REQUIREMENTS

1. Windows Operating System
2. John the Ripper
3. Johnny 2.2
4. 7-Zip
5. Web Browser
6. Notepad
7. My Locked PDF1.pdf
8. Internet Connection

4. PRACTICAL IMPLEMENTATION

STEP 1: DOWNLOADING JOHN THE RIPPER

John the Ripper was downloaded from the official Openwall website. The Windows 64-bit package was selected according to the system requirements.

STEP 2: EXTRACTING JOHN THE RIPPER

The downloaded JTR archive was extracted using 7-Zip. The extracted folder was opened, and the required application files were located inside the run directory.

STEP 3: DOWNLOADING JOHNNY

Johnny, the graphical interface for John the Ripper, was downloaded from its official webpage.

STEP 4: INSTALLING JOHNNY

The downloaded Johnny setup file was opened. The installation wizard was followed, and the installation was completed successfully.

STEP 5: CONFIGURING JOHNNY

Johnny was opened, and its settings were accessed. The John the Ripper executable was located in the extracted JTR folder and selected for configuration.

The configuration was checked to ensure that Johnny could detect the required application.

STEP 6: DOWNLOADING THE SAMPLE PDF

The password-protected sample document named My Locked PDF1.pdf was obtained from the NetworkWalks practical materials and saved on the computer.

STEP 7: PDF ANALYSIS

The practical instructions introduced an online PDF analysis service for examining the supplied document. The sample PDF was used for this exercise.

STEP 8: PREPARING THE REQUIRED INFORMATION

The information obtained during the analysis stage was saved in a text file using Notepad, as described in the lab instructions.

STEP 9: OPENING THE INFORMATION IN JOHNNY

The prepared lab information was opened through the Johnny interface for the practical exercise.

STEP 10: PERFORMING THE PRACTICAL

The configured John the Ripper application was used through Johnny to carry out the assigned lab exercise. The progress and displayed output were observed.

STEP 11: OBSERVING THE RESULT

The output displayed by the application was checked, and the practical result was recorded.

STEP 12: VERIFYING THE SAMPLE PDF

The supplied sample PDF was opened for verification using the result obtained during the exercise.
